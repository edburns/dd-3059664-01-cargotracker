## Section 8: Observations and Recommendations

### 8.1 What Worked Well

- **Complete serial delivery:** all five dependent tasks reached merge in under two hours with no human code intervention.
- **Effective merge gates:** current-head review checks, authoritative thread queries, branch checks, CI checks, and issue-closure confirmation prevented premature merges.
- **Review convergence:** the deepest task converged in three rounds, and two tasks required no review fixes.
- **Control-run integrity:** lesson propagation remained `off`; no validated lessons were recorded or injected into subsequent tasks.
- **Useful observability:** paired Markdown, session JSONL, and OTEL JSONL artifacts provide reproducible timing, outcome, and model-cost evidence.

### 8.2 What Could Improve

- **Create authoritative issue links up front.** Three of five PRs needed closing-link repair. Stage 30 should normalize and verify `Fixes #<task>` immediately after PR discovery rather than encountering the failure at a later readiness gate.
- **Harden campaign metadata extraction.** The empty campaign-ID attempt on [#7](https://github.com/edburns/dd-3059664-01-cargotracker/issues/7) indicates a parsing or field-name path that can temporarily produce an empty value. Read the persisted campaign contract once, validate required fields as non-empty, and reuse the typed result.
- **Emit structured stage summaries.** Each session should write a compact machine-readable result containing issue, PR, duration, review IDs, findings per round, fixes, final head, merge SHA, and outcome. This would eliminate post-hoc inference from Markdown transcripts.
- **Preserve token totals when policy permits.** Current OTEL token fields are redacted. A non-sensitive aggregate usage record would make campaign efficiency comparisons more complete.
- **Distinguish recovered gates from terminal failures.** Use a structured status such as `gate_failed_then_recovered` for transient contract violations. Reusing `SHEPHERD FAILED` makes successful sessions look terminally failed in text searches.
